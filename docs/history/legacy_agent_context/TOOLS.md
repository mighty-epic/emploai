# TOOLS.md - Local Notes

Skills define _how_ tools work. This file is for _your_ specifics.

## What Goes Here

- API keys and tokens
- Preferred models or services
- File paths and locations
- Device names
- Anything environment-specific

```markdown

- Browser tasks: claude-haiku

### File Paths

- Downloads: ~/Downloads
```
