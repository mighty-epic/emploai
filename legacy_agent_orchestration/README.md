# Legacy Agent Orchestration

This package contains older high-level, unified, dual-agent, and legacy web
orchestrator experiments. It is preserved for tests and reference, but the
current desktop product path runs through `app_backend/`, `desktop_runtime/`,
`local_agent_runtime/`, and `shared/`.

Prefer new work in `shared/`, `app_backend/`, or `local_agent_runtime/` unless
you are deliberately maintaining these legacy orchestration experiments.
