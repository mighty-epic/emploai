# Runtime Context

These markdown files are the bundled prompt/context defaults copied into a user's local runtime home on first start.

The live runtime reads user-specific copies from `EMPLOAI_HOME` or the default runtime home. Edit these files when changing the starter context for new local desktop installs.

The old Telegram-scoped location `telegram_bot/agent_data/` is kept only as a fallback in code for older checkouts.
